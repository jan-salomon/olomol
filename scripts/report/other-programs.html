olomol reading other programs' files

Every test file from RDKit's own tests (ChemDraw's CDXML and CDX, reactions as RXN), opened in olomol as a user opens a file. Each card shows the file as it draws itself, as olomol drew it, and the molecules RDKit's tests expect. Green: olomol reads what RDKit reads. Amber: it reads otherwise, and the card says why. Grey: RDKit's tests say nothing about the file, so the check only makes sure olomol keeps reading it as it did when that was written down.
